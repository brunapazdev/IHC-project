# Planejamento de Usabilidade (Método DECIDE)

| Etapa | Descrição |
| :---: | :---- |
| **D** | **Determinra os objetivos da avaliação** - Avaliar a usabilidade da interface proposta para visualização de impactos ambientais da computação em nuvem, identificando dificuldade de navegação, interpretação de gráficos e interação com filtros e dashboards. |
| **E** | **Explorar as perguntas da avaliação** - Os usuários conseguem compreender os indicadores ambientais? A navegação é intuitiva? Os gráficos facilitam a interpretação dos dados? Existem dificuldades na utilização de filtros e comparações? |
| **C** | **Escolher os métodos de avaliação** - Observação do usuário, avaliação heurística, questionários de satisfação e análise de tarefas realizadas durante o teste. |
| **I** | **Identificar questões práticas** - O teste será realizado remotamente utilizando notebook, navegador Google Chrome e conexão com internet. Será necessário registrar o comportamento do usuário, tempo de execução das tarefas e dificuldades encontradas durante a interação. |
| **D** | **Decidir como lidar com questões éticas** - O participante será informado sobre os objetivos do teste e deverá concordar com o termo de consentimento. Os dados coletados serão utilizados apenas para fins acadêmicos e não serão divulgadas informações pessoais. |
| **E** | **Avaliar, interpretar e apresentar os dados** - A análise e produção dos resultados precisam considerar vários aspectos, como tempo de execução das tarefas, quantidade de erros, grau de satisfação do usuário, dificuldades encontradas e possíveis melhorias para a interface. |

# Lista de Instrumentos

## 1. Termo de Consentimento

### Objetivo
Garantir que o participante esteja ciente dos objetivos da pesquisa e concorde com a realização do teste de usabilidade.

### Conteúdo
- Explicação sobre o objetivo da avaliação
- Garantia de privacidade dos dados
- Consentimento para observação e registro
- Uso acadêmico das informações coletadas

---

## 2. Questionários

### Objetivo
Coletar informações sobre:
- perfil do usuário;
- experiência com tecnologia;
- percepção sobre usabilidade;
- grau de satisfação com a interface.

### Tipos de questionário utilizados
| Tipo | Objetivo |
|---|---|
| Questionário de perfil | Identificar características do participante |
| Questionário pós-teste | Avaliar satisfação e dificuldades encontradas |

---

## 3. Tabela de Observação

### Objetivo
Registrar o comportamento do usuário durante a execução das tarefas.

### Itens observados
| Item observado | Objetivo |
|---|---|
| Tempo de execução | Avaliar eficiência |
| Quantidade de erros | Identificar dificuldades |
| Navegação | Verificar fluidez da interação |
| Compreensão da interface | Avaliar clareza visual |
| Reações do usuário | Identificar frustração ou satisfação |

---

## 4. Formulário de Avaliação Heurística

### Objetivo
Avaliar a interface com base nas heurísticas de Nielsen.

### Aspectos avaliados
| Heurística | Objetivo |
|---|---|
| Visibilidade do status do sistema | Verificar feedback da interface |
| Compatibilidade com o mundo real | Avaliar clareza da linguagem |
| Controle e liberdade do usuário | Verificar facilidade de navegação |
| Consistência e padrões | Avaliar padronização visual |
| Prevenção de erros | Identificar mecanismos preventivos |
| Reconhecimento em vez de memorização | Avaliar facilidade de uso |
| Flexibilidade e eficiência | Verificar adaptação a diferentes usuários |
| Estética e design minimalista | Avaliar organização visual |
| Reconhecimento e recuperação de erros | Verificar mensagens e recuperação |
| Ajuda e documentação | Avaliar suporte ao usuário |
